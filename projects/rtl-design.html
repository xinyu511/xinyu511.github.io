Matrix-vector accelerator on an FPGA

The design computes Y = A·B + C for a 128×128 matrix of 8-bit values on a Spartan-7 board. Sixteen dual-port block-RAM banks deliver 32 matrix elements per cycle to 32 parallel multipliers, followed by an adder tree and an accumulator. An extra register stage between the RAMs and the multipliers was what closed timing: the routed design meets 100 MHz with 0.70 ns of worst-case slack.

Network-on-chip

Six nodes connected through two routers. Each node splits 32-bit packets into 8-bit flits and reassembles them on the way out with a pair of FSMs and a small FIFO. Each router output port arbitrates between four inputs with a rotating-priority FSM that has one state per priority order (24 states), so no input can be starved. The design passes every course test, including broadcast, stress, fairness, and a 10,000-packet performance test that it completes in 15,931 cycles.

USB host, bit layer

With a partner, a USB host that reads and writes a device over the bus. I built the bit-level path: bit stuffing and unstuffing, NRZI encoding and decoding, driving and sampling the differential lines, bitstream decoding, and the read/write transaction FSM.
