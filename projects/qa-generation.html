Question answering and generation over long documents

Two pipelines over long articles: one answers questions about the text, the other writes questions a reader could ask.

Answering

Articles are much longer than the passages the models were trained on, so the pipeline first narrows them down. TF-IDF vectors and cosine similarity pick the passages most relevant to the question. A fine-tuned BERT classifier then decides whether the question is yes/no or asks for a span. Yes/no questions go to a T5-small fine-tuned on BoolQ; the rest go to a T5-small fine-tuned on SQuAD that extracts the answer span. Fine-tuning BERT on SQuAD for the span task gave much lower exact match than T5, so we kept T5.

Generating

YAKE extracts keywords from the passage; a T5-small fine-tuned on SQuAD treats each keyword as an answer and writes a question for it. We also tried few-shot prompting Llama-2 for both tasks and dropped it: it was slow and its output format was hard to control.

Results

The main failure we saw was questions that need implicit reasoning across sentences: the answering models only extract or classify, so they can't combine facts the text never states together. Dense passage retrieval was the next step we did not get to.
